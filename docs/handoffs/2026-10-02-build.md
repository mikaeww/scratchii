# Handoff 2026-10-02: first build, phases 0 to 9

## State

All phases of [the build plan](../plans/2026-10-02-buildplan.md) are done and pushed to the private repo
`mikaeww/scratchii`. `npm run check` passes (43 tests plus Rust format and clippy). The app runs in the browser
(`npm run dev`), as a desktop app (`./install.sh`, or `npm run desktop:build` for .deb and AppImage), and syncs
through `npm run server`.

## Decisions

- ADR 0001 web app plus Tauri, ADR 0002 Neo Brutalism light only, ADR 0003 checks and dependencies, ADR 0004
  boards stay in IndexedDB on the desktop too.
- Sync compares server revisions, never device clocks; `updated` grows monotonically per board; tombstones keep
  the board's own `updated` (docs/verification/sync.md).
- Marks carry their strokes inside the item, so own presets render everywhere (docs/verification/annotate.md).
- No autosave switch and no default-stroke setting; the last style is remembered (build plan, phase 9).

## Open

- Real-stroke corpus for shape snapping and handwriting recognition (only generated strokes are measured).
- The real app icon; `assets/icon-placeholder.svg` and `src-tauri/icons/` are placeholders.
- A screen reader pass; only names, focus and keyboard were checked.
- Publishing: the repo is private; the README is written for a public release.
