# Handoff 2026-10-05: clean shapes, more kinds, better snapping

## State

- Shapes render as clean geometry (`src/geometry/outline.ts`): true ellipses, straight edges, one open arrow
  head. roughjs is gone. Only sticky notes cast the hard shadow (ADR 0005).
- New item type `polygon` (corners as fractions of the box, `src/geometry/polygon.ts`); tools for triangle (3),
  diamond (D) and star (S) in the toolbar.
- Holding the pen still now also snaps triangles, diamonds, one-stroke stars, outline stars, tilted boxes and
  polygons up to six corners (`src/recognize/polygons.ts`); nearly round ellipses become circles, nearly square
  boxes squares, lines and arrows within 5° of a 45° step snap onto it. Recognised polygons are straightened
  (`src/recognize/straighten.ts`): sloppy boxes become exact level boxes (or exact rectangles when leaning 12°
  or more), nearly level edges level, a triangle's apex over the middle of its base.
- `npm run check` passes (47 tests); R1 500/500 for every new class, R2 unchanged. Headless scene
  `node tools/render.ts OUT shapes` shows tools and snapping side by side. README screenshots `board.png` and
  `recognise.png` re-rendered.

## Decisions

- ADR 0005 replaces the shadows-on-drawn-shapes part of ADR 0002.
- One `polygon` type instead of one type per shape: recognised triangles keep their drawn corners, and moving
  and scaling stay box arithmetic.

## Open

- Uncommitted work from 2026-10-04 (eraser path, pen resume after a snap, grid pattern, eslint bump) sits in the
  same tree and touches `src/editor/tools/pen.ts` too.
- Snapping is still measured only on generated strokes; the real-stroke corpus from the 2026-10-02 handoff is
  still the next step for recognition.
- Polygons cannot be rotated as a whole; a tilted ellipse cannot be represented.

## Next step

start the real corpus under `tests/fixtures/strokes/`.
